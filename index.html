How Nether coordinates work

The Nether has an 8:1 horizontal scale, making it useful for travelling long distances quickly.

➗

Overworld → Nether

Divide X and Z by 8. Y stays the same.

✖️

Nether → Overworld

Multiply X and Z by 8. Y stays the same.

Quick reference

Overworld → Nether: X ÷ 8 · Y unchanged · Z ÷ 8
Nether → Overworld: X × 8 · Y unchanged · Z × 8

Example: 800, 64, -400 in the Overworld corresponds to 100, 64, -50 in the Nether.

How to link Nether portals

  1. Read the X, Y and Z of your existing portal.
  2. Enter them into the calculator.
  3. Build the matching portal as close as practical to the calculated X and Z.
  4. Test the route in both directions. If it links incorrectly, check nearby portals too.

Java and Bedrock use the same basic 8:1 horizontal conversion, while some portal-linking details differ between editions.

Frequently asked questions

Common questions about Minecraft Nether coordinates and portal linking.

What is the Nether coordinate ratio?

The horizontal scale is 8:1. Divide X and Z by 8 going from the Overworld to the Nether, and multiply them by 8 coming back.

Does Y change?

No. Y is not scaled by the 8:1 conversion.

Does it work with negative coordinates?

Yes. You can enter negative X and Z values just like positive coordinates.

Why can a portal link to the wrong place?

When several portals are nearby, Minecraft can choose a different existing portal near the converted destination. Check the positions of nearby portals and build the intended pair deliberately.

Does it work on Java and Bedrock?

Yes for the basic coordinate conversion. Portal-linking behavior can differ between editions.
